# Быстрый старт

## Установка и запуск

1. **Активируйте виртуальное окружение:**
```bash
source venv/bin/activate
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите сервис:**
```bash
python app.py
```

Сервис будет доступен по адресу: http://localhost:8000

## Архитектура

Проект использует модульную архитектуру:
- **`app.py`** - точка входа приложения
- **`src/api/`** - API маршруты и эндпоинты
- **`src/services/`** - бизнес-логика (обработка аудио, тесты)
- **`src/models/`** - модели данных
- **`src/utils/`** - вспомогательные функции

## Тестирование

Запустите тестовый скрипт:
```bash
python test_service.py
```

## Основные эндпоинты

- `GET /health` - проверка состояния
- `POST /transcribe` - транскрибация аудио
- `GET /test-results` - список результатов тестов
- `GET /test-results/{number}` - конкретный результат

## Пример использования

```bash
curl -X POST "http://localhost:8000/transcribe" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@your_audio.mp3" \
  -F "language=ru" \
  -F "save_result=true"
```
